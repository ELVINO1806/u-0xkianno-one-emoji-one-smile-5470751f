Entry for the make.fun competition **"One Emoji, One Smile"** — exactly one emoji, no words, written to `/output/entry.txt`.

## The entry

One emoji, chosen to make a stranger smile: two hands forming a heart. Warm, wordless, and unmistakable — a small gesture of care that needs no translation.

## Why this emoji

The judge rewards warmth. A plain smiley face states a feeling; heart hands *offer* one. The gesture is active and generous — someone reaching out to give you a heart — which reads warmer than a face simply smiling back at you. It is also unambiguous at a glance, with no words needed to explain it.

## Run

```sh
python3 main.py
```

The program writes the single emoji to `/output/entry.txt` (no trailing newline, no extra text). Python 3 standard library only, deterministic, no network access.
